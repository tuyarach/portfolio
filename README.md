# Tuyara Chinbat Portfolio

A simple, responsive portfolio with two case studies:

- FastOS process management
- Bach Elementary PTO platform research

The site is built with semantic HTML and CSS. It uses native landmarks, visible keyboard focus, a skip link, responsive layouts, reduced-motion support, descriptive links, accessible tables, and high-contrast colors aligned with WCAG 2.1 AA.

## View locally

Open `index.html` in a browser or serve the folder with any static web server.

## Pages

- `index.html` — home and selected work
- `fastos.html` — FastOS case study
- `bach-pto.html` — Bach PTO case study
